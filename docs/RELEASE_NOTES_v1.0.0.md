# Math Research Agent v1.0.0

## Highlights

- Autonomous research orchestration
- Research branches and proof graph
- Bundled Python 3.12.10, SymPy, NumPy, SciPy, and Z3 experimentation
- Checkpoint, pause, resume, and restart recovery
- Evidence-aware proof review and exact counterexample workflows
- OpenAI-compatible providers
- Self-contained Windows x64 runtime

## Important

Math Research Agent is a mathematical research tool. LLM-generated arguments are not automatically proofs. `SURVIVED TESTING != PROOF`.

The installer is not signed with a commercial code-signing certificate, so Windows SmartScreen may display **Unknown publisher**. Download only from the project release page and verify the checksum below; do not disable Windows security globally.

## First run

1. Install and open Math Research Agent.
2. In Settings, configure your own OpenAI-compatible Provider, Base URL, model, and API key.
3. Run Runtime Diagnostics.
4. Create a project and start the research session.

Provider access, quotas, and model behavior are supplied by third parties and are not included in this release.
