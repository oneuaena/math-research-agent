## Signing boundary

The Windows executable is unsigned and may show SmartScreen “Unknown publisher.” The macOS applications are unsigned and not notarized, so first launch may require Control-clicking the app and choosing **Open**. Verify the SHA-256 values and do not disable system security globally.

## Research boundary

Model output is not automatically a mathematical proof. `SURVIVED TESTING` is not `FORMALLY VERIFIED`; only a successful, linked Lean kernel artifact receives the formal label.
