# Math Research Agent 2.1.0

## Human-in-the-Loop Live Research Steering

Version 2.1.0 adds a session-bound steering channel to Autonomous Research. A message sent from the Research page is retained as a conversation message and a durable `SteeringInstruction`; it is then applied by the orchestrator at safe boundaries. The agent remains autonomous when no steering exists.

Supported commands include adding hypotheses, evidence, constraints, branches, and lemma priorities; branch priority/pause/resume/abandonment; replanning; discovery/proof-search start and stop; resource/discovery changes; and research pause/resume. Free text keeps its original wording and is interpreted by the configured model into a restricted instruction schema when possible. A failed or unavailable interpretation never grants verification status and falls back conservatively.

## Safety boundaries

- User steering cannot bypass Formal Binding, Lean kernel checks, deterministic evaluators, or evidence/proof verification.
- A request to mark a result `VERIFIED` is rejected unless the existing verification gates independently permit it.
- Changing a theorem statement creates a claim version. Formal bindings, Lean certificates, and prior evidence remain attached to the earlier claim version.
- Retracted evidence is retained with audit metadata, dependent nodes are invalidated, and the affected branch is blocked pending re-evaluation.
- Pause/stop commands request cooperative cancellation and preserve worker checkpoints/results rather than deleting in-flight research state.

## Validation scope

The source release passes TypeScript checks, the full automated test suite, production bundling, and Windows packaged-runtime/autonomy smoke tests. Windows packaging is executed and smoke-tested on Windows. macOS archives are structurally validated on Windows only; they are unsigned and must be runtime-tested on macOS before relying on them in production.
