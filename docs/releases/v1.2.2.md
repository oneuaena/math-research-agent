# Math Research Agent 1.2.2

This release corrects a provenance flaw in the initial Formal Binding Gate. It does not add a new mathematical search engine or claim a solution to semantic-equivalence verification.

## What changed

In 1.2.1, an autonomous `lean_check` could create a new binding from the Lean source submitted at verification time. That detected a declaration change only *after* a model had chosen both sides of the mapping. Version 1.2.2 removes that path.

1. `FORMALIZE` stores the structured specification and may propose a proof-free Lean declaration header.
2. The main process freezes the original statement, Formal IR, Lean declaration, SHA-256 hashes, combined binding hash, and mapping authority before a proof starts.
3. Every later Lean call must pass an existing frozen `bindingId`; the declaration header in its source must match exactly. No binding is created by `lean_check`.
4. The same rule applies to provider-native tool calls. General renderer record APIs cannot write or delete frozen bindings.
5. An AI-proposed mapping is labelled `LEAN_STATEMENT_ONLY — original-language equivalence not independently certified`. It may retain a kernel certificate for the Lean statement, but it cannot promote the original language claim/proof to `VERIFIED`.
6. Formal Lab has an explicit user-confirm-and-freeze step. Only a user-confirmed mapping can enter the existing proof-promotion gate, which still also requires exact proof linking, independent review, valid critical steps, and kernel success.

## Scope and limitations

The change makes the claim-to-Lean provenance chain stable and auditable. It does **not** automatically establish that a model-generated Lean declaration is semantically equivalent to a natural-language theorem. It also does not turn finite experiments, symbolic transformations, Z3 encodings, or model agreement into a proof.

No finite validation suite can guarantee the absence of all bugs. This release is validated on Windows; macOS packages are structurally validated on Windows and must be dynamically launched on real Apple Silicon and Intel hardware before such a claim can be made.
