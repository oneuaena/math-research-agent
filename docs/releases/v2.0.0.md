# Math Research Agent 2.0.0

Math Research Agent 2.0.0 is a major local-first upgrade focused on auditable mathematical discovery and formal-search feedback loops. It does **not** claim autonomous solution of arbitrary open problems, semantic equivalence between natural language and Lean, or an absence of future defects.

## Delivered capabilities

- A declarative Candidate Representation Layer covering set/subset, tuple, sequence, permutation, matrix, graph, hypergraph, integer vector, boolean vector, structured object, and a non-executable expression-tree DSL.
- A deterministic, hash-addressed evaluator DSL with feasibility constraints, minimization/maximization/target objectives, Pareto/lexicographic/weighted aggregation, candidate certificates, seed/audit data, bounded worker evaluation, and evolutionary/random/hill-climbing/beam/annealing strategies.
- Validation before execution: schema, static bounds, small case, and adversarial evaluator checks. Arbitrary evaluator code, shell commands, network access, process spawning, filesystem operations, and `eval` are not part of the discovery evaluator language.
- Autonomous workflow integration through `DISCOVERY_SEARCH`, `DISCOVERY_ANALYZE`, and `DISCOVERY_REFINE`; discovery results become scoped evidence, candidate nodes, knowledge records, and inputs to lemma/proof stages.
- N71-safe representation coverage: a 71 × 71 universe and 142-point no-three-in-line evaluator can be represented without the former 4096-universe cap. The regression validates representation/evaluator safety only; it does not claim to solve N71.
- Bounded frozen-binding Lean proof search with goal probing, restricted tactic candidates, independent compiler checks, attempt/partial-state records, beam records, cancellation checkpointing, and kernel-only certification.
- A shared persisted resource ledger, cross-project attributed knowledge records, fixed Level 1–4 benchmarks, and recorded `falseVerifiedRate`.

## Trust boundaries

`FORMALLY VERIFIED` remains reserved for Lean kernel acceptance of the frozen declaration plus the established proof-promotion requirements. A kernel certificate for an `AI_PROPOSED` mapping remains `LEAN STATEMENT ONLY`; it does not independently certify the original natural-language statement. A discovery candidate is evaluator-scoped computational evidence, not a theorem.

## Validation summary

- TypeScript typecheck and ESLint passed.
- 27 test files passed: 95 passed and 1 environment-conditional test skipped.
- Regression coverage includes generic/legacy discovery, all representations, evaluator rejection, deterministic certificates, pause/resume, migration compatibility, N71 representation, orchestration linkage, formal binding/proof search, and benchmark truth labelling.
- Windows package/runtime validation is performed after release assembly. macOS archives are structurally validated on Windows; runtime launch on Apple hardware is not asserted from a Windows host.
